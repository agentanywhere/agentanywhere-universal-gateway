# Python support: 3.10, 3.11, 3.12 (see pyproject requires-python).

# The three ML pins below are ranges, not ==, because the 2023-era versions
# (numpy 1.24.3, pandas 2.1.3, scikit-learn 1.3.2) ship no cp312 wheels. pip
# falls back to an sdist build and old numpy's setup.py calls
# pkgutil.ImpImporter, removed in 3.12 -- so `pip install -r requirements.txt`
# failed outright on 3.12 while pyproject claimed ">=3.10".
#
# sqlalchemy carries the [asyncio] extra so greenlet is installed explicitly.
# Without it the async DB layer raises "the greenlet library is required" at
# runtime on 3.12 -- the gateway, not just the tests.
#

# full-stack modernisation with real regression risk, deliberately not done here.
